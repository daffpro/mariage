# Takk Djakk — 11 octobre 2026

Faire-part animé du mariage religieux (mosquée de Khar Yallah).

Page unique et statique : `index.html` (alliances en or en 3D avec three.js, compte à rebours, arc et mosquée dorés).

Ouvrir `index.html` dans un navigateur, ou activer GitHub Pages sur la branche `main` pour avoir un lien à partager.

L'heure de la cérémonie n'est pas encore fixée : le compte à rebours vise le dimanche 11 octobre 2026 à 00:00 (heure de Dakar). Pour la changer, modifier `TARGET` dans le script.
