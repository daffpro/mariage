# Takk Djakk — 11 octobre 2026

Faire-part animé du mariage religieux de Mouhamed & Astou, dimanche 11 octobre 2026 à 16h45, mosquée de Khar Yallah.

Page unique et statique, qui tient sur un seul écran :
- ouverture : « Cliquer ici 👆🏾 » sur le sceau d'or, rideaux qui s'écartent, verset Ar-Rûm 30:21 ;
- récitation d'Al-Husary (`assets/ar-rum-30-21-husary.mp3`, source everyayah.com), lancée à l'ouverture et jouée en boucle ;
- alliances en or 3D (three.js), calligraphie « Takk Djakk » écrite à l'or ;
- compte à rebours jusqu'à 16h45 (heure de Dakar), étincelles d'or au toucher.

Ouvrir `index.html` dans un navigateur, ou activer GitHub Pages sur la branche `main` pour avoir un lien à partager.
Pour changer l'heure, modifier `TARGET` dans le script.
